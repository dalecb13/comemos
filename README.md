# Comemos

`Comemos` is a mobile app that helps people figure out what restaurants to go to using the same swiping method in Tiner and other dating apps. People can use this by themselves or they can add people to a Match Game to find restaurants. This app is built using Expo + React Native and [Supabase](https://supabase.com/docs).

## Getting Started

1. Clone this repo
2. Set up Supabase via `supabase start`
3. Start local development environment via `npm run ios` or `npm run android`
